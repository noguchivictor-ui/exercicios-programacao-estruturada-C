# Programação Estruturada em C

Repositório dedicado aos exercícios, listas e trabalhos práticos desenvolvidos na disciplina de **Programação Estruturada**, utilizando a linguagem **C**.

## 🎯 Objetivo

Consolidar os fundamentos da programação estruturada e da linguagem C, incluindo:
- Variáveis, tipos de dados e operadores
- Estruturas condicionais (`if/else`, `switch`) e de repetição (`for`, `while`, `do-while`)
- Vetores, matrizes e manipulação de strings
- Funções, passagem de parâmetros e escopo
- Ponteiros e alocação dinâmica de memória
- Estruturas (`struct`) e manipulação de arquivos
